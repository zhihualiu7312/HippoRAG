1. **Granularity mismatch**: Only two granularities (Passage + Entity), missing macro-level document context (Paper), causing structural message passing to get disoriented in entity-dense graphs.
2. **Noise cascade**: Static text-agnostic diffusion propagates query-irrelevant information uniformly, overwhelming signals with noise in large graphs (e.g., 110k+ entity nodes).

### 요지 (Summary / Key Points)

1. **Tri-granular graph topology**: Injecting paper-level nodes to bridge macro-level document context with localized entity-passage semantics, eliminating "missing the forest for the trees."
2. **Differentiable query-aware gating**: Smooth sigmoid gates controlled by an MLP policy network, dynamically filtering noise nodes based on query-node embedding similarity.
3. **Learned Mixture of Granularity (MoG) routing**: A lightweight MLP outputs 7 parameters (α, β, γ, τ_pass, τ_paper, τ_ent, d_factor) per query, enabling end-to-end backpropagation through the graph diffusion.

1. The overall tri-granular graph architecture (Passage–Paper–Entity) with LLM-summarized paper node embeddings.
2. The differentiable query-aware gating mechanism with per-granularity sigmoid gates and adaptive thresholds.
3. The learned MoG policy network that predicts routing weights, filtering thresholds, and damping factor from query embeddings.
4. The end-to-end training framework with pairwise hinge loss for graph diffusion parameter learning.

**Difference from Prior Art:**
1. Tri-granular topology (Passage + Paper + Entity) vs. bi-granular (Passage + Entity only).
2. Query-aware dynamic gating vs. static text-agnostic diffusion.
3. Learned MLP-based parameter prediction vs. fixed heuristic parameters.
4. End-to-end differentiable training vs. non-trainable PPR.

## Slide 5: 발명의 배경 (Background of Invention) — Scenario / Motivation

**Samsung Confidential | Attorney-Client Privileged**

### Scenario: Knowledge graph-based retrieval for semiconductor domain

- **Objective**: Build knowledge graphs and invent an enhanced retrieval algorithm for public data (semiconductor domain papers and patents), to be integrated into the Knowledge Agent of DS Co-Scientist.

- **Target task**: BLPM (a target task of Co-Scientist) — paper search and patent search using "open questions" and related technical keywords.

- **Performance target**: Recall@K 30% improvement from the baseline.

### Motivation: Two fundamental limitations of existing Graph-RAG

1. **Granularity mismatch**:
   - Standard frameworks construct graphs with only two granularities: Passages (text blocks) and Entities (lexical items).
   - This binary formulation omits the macroscopic contextual anchor provided by the overarching document structure (Papers).
   - Without a macro-level node to bind correlated passages, structural message passing gets disoriented in entity-dense graphs — "missing the forest for the trees."

2. **Noise cascade**:
   - Traditional PPR employs a fixed transition matrix where information spreads indiscriminately across all edges.
   - In complex datasets (e.g., Musique), the graph explodes into massive configurations (110k+ entity nodes).
   - Under flat, text-agnostic PPR, query-irrelevant entities act as infectious hubs, proliferating semantic noise.
   - Retrieval accuracy at intermediate boundaries (Rec@10, Rec@20) suffers dramatic degradation.

## Slide 8: 발명의 구성 (2/3) — Composition of Invention

**Samsung Confidential | Attorney-Client Privileged**

### Motivation of this invention:

- Employing a **differentiable, query-aware gating mechanism** to achieve adaptive information routing on knowledge graphs.

- Designing a **tri-granular graph topology** (Passage–Paper–Entity) to fully leverage multi-level structural prior knowledge for robust and accurate retrieval.

1. **First, construct a tri-granular graph** by introducing paper-level nodes that aggregate passages under the same document, providing macro-level semantic anchoring:
   - Paper node embeddings are generated by LLM-summarizing all passages under the same title, ensuring macro-scale semantic consistency.
   - Passage-paper edges are weighted by cosine similarity between passage and paper embeddings.

2. **Second, apply query-aware gating** to suppress irrelevant nodes before diffusion:
   - Sigmoid gate function: `g_v = σ(k × (sim(q, v) − τ_T))` where τ_T is a per-granularity threshold.
   - Gates are applied to passage, paper, and entity nodes independently.

3. **Finally, run gated PPR diffusion** with parameters predicted by a learned MoG policy network:
   - The MLP outputs 7 parameters per query: routing weights (α, β, γ), thresholds (τ_pass, τ_paper, τ_ent), and damping factor (d_factor).
   - All operations are differentiable, enabling end-to-end training.

## Slide 9: 발명의 구성 (3/3) — Composition of Invention

**Samsung Confidential | Attorney-Client Privileged**

### Five core modules of the proposed system:

**1. Tri-Granular Graph Topology Construction**
: Define the heterogeneous knowledge graph G = (V, E) where V = V_pass ∪ V_paper ∪ V_ent. For each document, create a paper node v ∈ V_paper. Every passage u ∈ V_pass is connected to v via a composition edge (u, v) ∈ E. The paper node representation e_paper is derived by LLM-summarizing and encoding all constituent passages.

**2. Query-Aware Gating Mechanism**
: Given a query vector q and a node v, compute semantic similarity sim(q, v) via cosine distance. Apply a smooth differentiable sigmoid gate: g_v = σ(k × (sim(q, v) − τ_T)), where k is a scaling hyperparameter and τ_T is the dynamically predicted activation threshold for node type T ∈ {pass, paper, ent}.

**3. Differentiable Personalized PageRank**
: Construct a diagonal gating matrix G where G_ii = g_{v_i}. The gated transition matrix M_gated = A · G. The PPR vector is solved iteratively: p^(d+1) = d_factor · p_0 + (1 − d_factor) · M_gated · p^(d), where d_factor is the damping parameter and p_0 is the query personalization vector.

**4. Learned Mixture of Granularity (MoG) Policy**
: A lightweight MLP acts as the central policy controller, outputting 7 parameters: Θ = MLP(q) = [α, β, γ, τ_pass, τ_paper, τ_ent, d_factor]. Here (α, β, γ) are soft routing weights distributing informational flow among heterogeneous node subsets; τ values feed into gate computation; d_factor controls diffusion depth.

**5. End-to-End Training Framework**
: Supervise the MoG policy network using a pairwise hinge loss: L = max(0, Δ − p(v+) + p(v−)) + λ‖W‖₂, where v+ is a ground-truth positive passage, v− is a hard-negative passage, Δ is the margin, and λ‖W‖₂ imposes weight decay regularization.

## Slide 13: Invention Details (1/5) — Tri-Granular Graph Topology

**Samsung Confidential | Attorney-Client Privileged**

### Tri-Granular Graph Topology Construction

**Flowchart:**

```
Documents (Papers/Patents)
    ↓
[Text Preprocessing & Chunking]
    ↓
┌─────────────────────────────────────┐
│  OpenIE (NER + Triple Extraction)  │ → Entity nodes (V_ent)
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  Passage Embedding                  │ → Passage nodes (V_pass)
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐     ← Novel module
│  LLM Summarization per Document     │
│  + Paper Embedding                  │ → Paper nodes (V_paper)
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  Edge Construction:                 │
│  - Entity-Entity (fact edges)       │
│  - Entity-Passage (passage edges)   │
│  - Entity-Entity (synonymy edges)   │
│  - Passage-Paper (composition edges)│  ← Novel
└─────────────────────────────────────┘
    ↓
Tri-Granular Knowledge Graph G = (V, E)
```

**Details:**

: **Paper node creation**: For each document, group all passages by title metadata. Use LLM to generate a comprehensive summary of all passages under the same title. The paper text = title + LLM summary. Encode paper text to obtain paper embedding.

: **Passage-Paper edges**: Weight = cosine similarity between passage embedding and paper embedding, clipped to [0, 1].

: **Paper node integration**: Paper nodes are added to the graph alongside entity and passage nodes, forming a three-layer hierarchical structure.

## Slide 14: Invention Details (2/5) — Query-Aware Gating Mechanism

**Samsung Confidential | Attorney-Client Privileged**

### Query-Aware Multi-Granularity Gating

**Flowchart:**

```
Query Embedding (q)
    ↓
┌─────────────────────────────────────────┐
│  Compute sim(q, v) for all nodes v      │
│  via cosine similarity                   │
└─────────────────────────────────────────┘
    ↓
┌──────────────────────────┐  ┌──────────────────────────┐  ┌──────────────────────────┐
│  Passage Gate            │  │  Paper Gate              │  │  Entity Gate             │
│  g_v = σ(k·(sim−τ_pass)) │  │  g_v = σ(k·(sim−τ_paper))│  │  g_v = σ(k·(sim−τ_ent)) │
└──────────────────────────┘  └──────────────────────────┘  └──────────────────────────┘
    ↓                               ↓                               ↓
    └───────────────┬───────────────┘───────────────┬───────────────┘
                    ↓                               ↓
            Gated Reset Vector (node_weights × gates)
```

**Details:**

: **Sigmoid gate function**: g_v = σ(k × (sim(q, v) − τ_T)), where σ is the Sigmoid function, k is a scaling hyperparameter (slope hardness, default k=3.0), and τ_T is the activation threshold for node type T.

: **Adaptive threshold**: When enabled, the threshold is computed from top-N similarity statistics: τ = mean(top-N sims) + α × std(top-N sims), bounded to [τ_min, τ_max].

: **Gate entropy monitoring**: Normalized Shannon entropy H = −Σ p·log(p) / log(N) is computed per granularity to monitor information flow distribution.

: **MoG routing weights**: Gates are multiplied by routing weights (α, β, γ) predicted by the MoG policy network, distributing informational flow among granularities.

## Slide 15: Invention Details (3/5) — Differentiable Personalized PageRank

**Samsung Confidential | Attorney-Client Privileged**

### Gated PPR Diffusion

**Flowchart:**

```
Seed Scores (p_0)
    ↓
┌─────────────────────────────────────────┐
│  Apply Node Gates to Reset Vector      │
│  p_0_gated[i] = p_0[i] × g_i           │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Construct Gated Transition Matrix     │
│  M_gated = A · G                        │
│  where G = diag(g_1, ..., g_|V|)       │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Iterative PPR Diffusion               │
│  p^(d+1) = d·p_0 + (1−d)·M_gated·p^(d)│
│  for d = 0, 1, ..., depth-1            │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Extract Passage Node Scores           │
│  → Rank passages by PPR score           │
└─────────────────────────────────────────┘
    ↓
Ranked Retrieval Results
```

**Details:**

: **Gating matrix**: G ∈ R^(|V|×|V|) is a diagonal matrix where G_ii = g_{v_i}. The gated transition matrix M_gated = A · G dynamically scales transition probabilities based on query relevance.

: **Adaptive damping**: The damping factor d_factor is predicted by the MoG policy network per query, replacing the fixed damping used in standard PPR.

: **Full graph mode**: When enabled, diffusion runs on the full graph using igraph's optimized prpack implementation with adaptive damping = 1 − restart, where restart is predicted by the policy.

: **Local subgraph mode**: When enabled, a query-induced local subgraph is constructed via BFS from seed nodes, and diffusion runs on the subgraph using a custom Python PPR implementation.

: **Query-aware edge weighting** (optional): Edge weights can be dynamically adjusted based on query-node similarity: w_new = w_old × sim(src) × sim(dst) (multiply mode), or (w_old + sim(src) + sim(dst))/3 (add mode), or w_old × (1 + 0.5 × avg_sim) (boost mode).

## Slide 16: Invention Details (4/5) — Learned MoG Policy Network

**Samsung Confidential | Attorney-Client Privileged**

### Mixture of Granularity (MoG) Policy

**Flowchart:**

```
Query Embedding (q ∈ R^D)
    ↓
┌─────────────────────────────────────────┐     ← Novel module
│  MoG Policy Network (MLP)              │
│  Architecture:                          │
│  Linear(D → hidden_dim) → ReLU          │
│  → Linear(hidden_dim → 7)              │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Output: 7 Parameters                   │
│  Θ = [α, β, γ,                          │
│       τ_pass, τ_paper, τ_ent,           │
│       d_factor]                          │
└─────────────────────────────────────────┘
    ↓
    ├─→ (α, β, γ): Softmax → routing weights
    │   α + β + γ = 1
    │   α: passage routing weight
    │   β: paper routing weight
    │   γ: entity routing weight
    │
    ├─→ (τ_pass, τ_paper, τ_ent): Sigmoid → thresholds ∈ [0, 1]
    │   Used in gate function: g_v = σ(k·(sim − τ_T))
    │
    └─→ d_factor: Sigmoid → damping ∈ [0.3, 0.95]
        Used in PPR: p^(d+1) = d·p_0 + (1−d)·M_gated·p^(d)
```

**Details:**

: **Network architecture**: A 2-layer MLP with ReLU activation. Input dimension = query embedding dimension (e.g., 4096). Hidden dimension = 32. Output dimension = 7.

: **Softmax for routing weights**: The first 3 outputs are passed through softmax to ensure α + β + γ = 1, distributing informational flow among passage, paper, and entity granularities.

: **Sigmoid for thresholds**: The next 3 outputs are passed through sigmoid to map to [0, 1], providing per-granularity activation thresholds.

: **Sigmoid for damping**: The last output is mapped to [0.3, 0.95] via sigmoid, controlling the exploration-exploitation tradeoff in PPR.

: **Heuristic fallback**: When learned policy is unavailable, a heuristic MoG router uses softmax over mean query-node similarities per granularity, with temperature parameter controlling sharpness.

## Slide 17: Invention Details (5/5) — End-to-End Training Framework

**Samsung Confidential | Attorney-Client Privileged**

### End-to-End Training with Pairwise Hinge Loss

**Flowchart:**

```
Training Data: (query, positive_passage, negative_passage)
    ↓
┌─────────────────────────────────────────┐
│  Forward Pass:                         │
│  1. MoG Policy → Θ = MLP(q)            │
│  2. Gating → g_v for all nodes          │
│  3. Gated PPR → p (retrieval scores)    │
│  4. Extract p(v+) and p(v-)            │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Loss Computation:                     │
│  L = max(0, Δ − p(v+) + p(v−))        │
│    + λ‖W‖₂                             │
│                                        │
│  where:                                │
│  Δ = margin hyperparameter              │
│  v+ = ground-truth positive passage     │
│  v− = hard-negative passage             │
│  λ‖W‖₂ = weight decay regularization   │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Backpropagation:                      │
│  Gradients flow through:               │
│  - PPR iteration (sparse matmul)        │
│  - Sigmoid gates                        │
│  - MoG Policy MLP weights              │
└─────────────────────────────────────────┘
    ↓
Updated MoG Policy Network
```

**Details:**

: **Hard negative mining**: Negative passages v− are dynamically mined from the top-5 scoring retrieved instances during early epochs, ensuring challenging training examples.

: **Differentiable path**: All operations — from query-conditioned sigmoid gate computation to iterative sparse matrix-vector multiplication — are continuous, enabling gradient flow back to MLP parameters.

: **Weight decay**: λ‖W‖₂ regularization counters overfitting on dense graphs with 110k+ entity nodes.

: **Training configuration**: Margin Δ, learning rate, weight decay λ, and hidden dimension are configurable. Best configuration: k=3.0 (gate slope), d_restart=0.3 (min restart), hidden_dim=128.

### The claim items may include:

1. **The overall tri-granular graph architecture** (Passage–Paper–Entity), including:

   - Per-granularity sigmoid gate function: g_v = σ(k × (sim(q, v) − τ_T)).

   - Gate entropy monitoring for multi-granularity information flow analysis.

   - Gated transition matrix: M_gated = A · G.
   - Adaptive damping factor predicted per query.

   - MLP architecture: query embedding → 7 parameters (α, β, γ, τ_pass, τ_paper, τ_ent, d_factor).

   - Heuristic MoG fallback using softmax over mean similarities.

5. **The end-to-end training framework**, including:
   - Pairwise hinge loss with hard negative mining.
   - Differentiable sparse matrix operations for gradient flow.
   - Weight decay regularization for dense graph training.

   - Adaptive linking_top_k based on fact score distribution.
